# 鼠标波纹与吸积盘渲染模式设计

## 目标

新增两个独立的全局渲染配置：鼠标点击波纹模式、吸积盘线条渲染模式。配置通过 Qt UI 修改并持久化，运行时传递到桌面渲染器和 Qt 预览。

## 鼠标点击波纹

提供三个模式：常驻开启、随黑洞启用、常驻关闭（默认）。常驻开启在程序运行且渲染器可接收桌面画面时监听点击；随黑洞启用仅在黑洞实际渲染进程运行时监听，空闲检测等待期间不响应；常驻关闭不监听且不执行波纹计算。

点击生成带屏幕坐标、开始时间、半径和强度的短生命周期波纹实例。桌面捕获画面合成时，波纹对局部背景采样坐标产生径向折射偏移，并叠加窄高光边缘；实例达到最大半径或强度衰减到阈值后回收。实例数量有固定上限，超出时丢弃最旧实例，避免内存和 GPU 工作量无界增长。

## 吸积盘线条渲染

提供三个全局模式：柔化（默认）、线条化、边缘柔滑。柔化保持当前生产效果；线条化提高原有高频条纹对比度，恢复清晰线条；边缘柔滑保留主体线条对比度，同时对原线条适度柔化，并在大于原线条半径的范围增加低强度平滑过渡层。模式值不属于预设参数，切换预设不会覆盖。

主渲染 Shader 与 Qt 预览 Shader 使用相同模式分支和参数语义。未知配置值回退到默认模式。关闭或停止黑洞时不改变已保存模式。

## UI 与配置

在黑洞渲染设置区域增加两个下拉控件，显示中文模式名并立即更新核心属性；保存配置时写入独立键，加载缺失键时使用默认值。现有配置文件和预设格式保持向后兼容。

## 验证

编译检查不得出现新增错误或警告。静态检查确认三种波纹状态、三种吸积盘模式均完整贯通 UI、配置、核心、渲染器和 Shader。运行验证覆盖点击位置、波纹衰减、黑洞未显示时的联动禁用，以及三种线条模式的画面差异；Qt 预览与生产路径分别验证。

## 风险与边界

波纹属于桌面后处理，不能改变原始捕获内容；捕获失败时跳过波纹并保持黑洞现有错误路径。波纹和线条模式均不修改自动生成文件。视觉效果以视频中的“底图随波变形并带边缘高光”为目标，不宣称像素级一致。
