# 黑洞浮现候选实施计划

目标：实现用户已确认的固定位置单次动画，先验收自然程度，再添加随机调度和水波参数配置。

反馈修订：用户否定第一版固定位置候选，第二版改为每次随机位置及大小，整轮仅触发一个出场水波；单周期波纹 1.2 秒按压回弹后归零，约 10.7 秒完成动画。状态与 GPU 回归、两次实际运行和独立测试包已完成，当前等待人工验收。

第三版反馈修订：用户明确要求出现时仅外扩、消失时内缩。伴随波纹现已采用显式传播方向，分别在 0.3 秒/9.5 秒触发一个 1.2 秒宽波面；取消按压回弹公式，保留随机位置/大小。状态与 GPU 方向回归、实际运行及第三版测试包核验已通过，等待人工验收。

第四版反馈修订：用户认可水波，要求恢复常规随机移动及大小/生长配置，消失时缩小而非淡出。候选不再覆盖固定大小、生长、鼠标跟随或当前中心；关闭生长分支修复为完整稳定大小。时间轴以平滑尺寸 0→1→0 代替透明度，两个事件读取同帧 Shader 实际中心，保持已验收水波方向和公式。Renderer/UI 构建及 CTest 5/5、9/9 通过；实际运行两个事件各一次且中心发生移动，10.709 秒正常退出。第四版 `build/BlakholeUI-emergence-roaming-shrink-20261013` 及 ZIP 已完成，程序与全部 Shader 哈希一致，等待人工验收。

当前架构：纯时间轴控制展开、停留、缩小；主渲染器通过专用启动参数播放一次，以出场尺寸倍率叠加常规大小配置，沿用常规移动路径。系统水波不受鼠标波纹开关影响。UI 复用现有进程管理和诊断流程启动预览，运行期间不允许重入。

当前约束：普通黑洞、仅选定显示器；尊重常规出生位置、随机轨迹和鼠标跟随配置；保留用户配置与收款码文件；本轮不发布、不推送。预览由用户主动触发，自动随机间隔与波纹配置待动画验收后接入。下方阶段记录保留初版实施历史。

第五版尺寸修订：用户要求按实际效果限制浮现模式大小。仅在浮现模式开启主体尺寸限制，按当前吸积盘外半径和屏幕比例计算完整尺寸缩放，使盘主体直径约为短边 40% 以内。系数作用于完整生长曲线，保留生长、固定大小和小尺寸配置，不改变普通模式。分两阶段执行：Shader/GPU 回归；主程序/UI 接入及完整构建、独立候选包核验。

第五版核验结果：Renderer/UI 构建及 CTest 5/5、9/9 通过，GPU 在短边 500 像素的横/竖/超宽屏验证盘主体直径为 200 像素，增长仍连续，小尺寸不放大。实际预览 10.711 秒正常退出，出场/退场波纹各一次。`build/BlakholeUI-emergence-size-limited-20261013` 及 ZIP 已生成并核验程序与全部 Shader 哈希，等待人工视觉验收；旧候选保留，本轮不推送。
