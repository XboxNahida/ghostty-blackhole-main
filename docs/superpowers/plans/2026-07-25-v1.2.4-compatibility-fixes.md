# v1.2.4 兼容性修复实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复已确认的 Shader、Bloom、混合 DPI、零移动速度、重复 Renderer 和 WGC 帧生命周期问题，并发布 v1.2.4。

**Architecture:** 保留现有 OpenGL、WGC/DXGI 自动选择和 Qt 配置结构。视觉修复采用最小 Shader/QML 改动；Renderer 实例键与 DPI 初始化抽成小型原生模块；WGC 将帧池对象封装在捕获模块内，OpenGL 路径只接收已 Map 的 staging 数据，预留 D3D11 路径只接收稳定 GPU 副本。

**Tech Stack:** C++17、Win32、WGC ABI、D3D11、OpenGL 3.3、Qt 6/QML、CMake、CTest、PowerShell。

## 全局约束

- 正式版本为 `1.2.4`，标签为 `v1.2.4`，构建目录为 `_build_v124_renderer` 和 `_build_v124_ui`。
- 不调整 Bloom 泛白、HDR 或对比度算法。
- WGC capture frame 必须存活到 staging Map 或稳定 GPU 副本同步完成。
- DXGI Acquire/ReleaseFrame 语义保持不变。
- 不修改用户本地配置、名单、ZIP、收款码和旧版备份。
- 源码与文档使用 UTF-8；正式包继续包含本地两张收款码，但 Git 不提交它们。
- 每个任务先 RED、再最小 GREEN、再运行相关回归；每阶段结束更新 `debug_state.md`。

### Task 3: WGC 捕获帧生命周期

**Files:**
- Modify: `src/capture_wgc.h`
- Modify: `src/capture_wgc.cpp`
- Modify: `src/main.cpp`
- Modify: `src/d3d11_renderer.h`
- Modify: `src/d3d11_renderer.cpp`
- Modify: `tools/check_v124_compatibility.ps1`

**Interfaces:**
- Produces: `bool WGC_TryGetMappedFrame(WGCCapture&, D3D11_MAPPED_SUBRESOURCE&, int&, int&)`；预留 D3D11 路径使用 `ID3D11Texture2D* WGC_GetStableFrame(WGCCapture&)`。
- Consumes: 每个成功的 `WGC_TryGetMappedFrame` 必须配对 `WGC_UnmapStaging`；稳定纹理由调用方 Release，但绝不是 WGC 帧池纹理。

- [ ] **Step 1: 写 WGC 生命周期 RED 契约**

要求头文件不再声明 `WGC_GetFrame`/`WGC_CopyToStaging`；OpenGL 主循环调用 `WGC_TryGetMappedFrame`；实现中 `frame->Release()` 的位置晚于 `Map`；预留 D3D11 路径只调用 `WGC_GetStableFrame`。

- [ ] **Step 2: 验证 RED**

Run: `powershell -File tools/check_v124_compatibility.ps1`

Expected: FAIL，报告 WGC 仍暴露帧池纹理和提前释放。

- [ ] **Step 3: 实现 OpenGL 稳定 Map API**

在单个函数内执行：`TryGetNextFrame`、保留 frame、获取 surface/texture、读取尺寸、`CopyResource(staging, texture)`、阻塞 `Map(D3D11_MAP_READ)`，最后释放 texture、surface、frame。任何失败都释放已取得的 COM 对象并返回 false。

- [ ] **Step 4: 迁移主屏、副屏和预热调用点**

WGC 分支直接取得 mapped staging 并上传；成功后 Unmap。DXGI 分支保持 `DXGI_GetFrame`、Copy、ReleaseFrame 原顺序，禁止用三元表达式混合两种所有权模型。

- [ ] **Step 5: 保持预留 D3D11 编译路径安全**

`WGC_GetStableFrame` 在 frame 存活期间复制到 WGC 自有默认纹理并等待复制完成，然后才释放 frame，返回稳定纹理引用。删除 D3D11Renderer 中以 AddRef 和延迟两帧防止帧池复用的错误假设与队列。

- [ ] **Step 6: 验证阶段三**

Run: `powershell -File tools/check_v124_compatibility.ps1`

Expected: `V124_COMPATIBILITY_OK`。

Run: `cmake --build _build_v124_renderer --config Release --clean-first`

Run: `cmake -S . -B _build_v124_d3d11 -G "MinGW Makefiles" -DCMAKE_BUILD_TYPE=Release -DCMAKE_CXX_FLAGS="-DBLACKHOLE_USE_D3D11"`

Run: `cmake --build _build_v124_d3d11 --config Release --clean-first`

Expected: 两条路径零新增错误；记录既有警告。

- [ ] **Step 7: WGC 运行冒烟**

在 Win11 强制 WGC，分别运行单屏、跨屏和一屏一黑洞；持续移动窗口/播放视频至少 60 秒，确认无撕裂、局部旧帧、闪烁、崩溃和残留 Renderer。
