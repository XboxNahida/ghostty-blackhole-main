# 鼠标波纹与吸积盘渲染模式实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**目标：** 为黑洞桌面渲染增加点击波纹三模式和吸积盘线条渲染三模式，并在 Qt UI 中持久化配置。

**架构：** Qt 核心保存全局模式并向渲染进程传递；渲染器在桌面捕获合成阶段维护固定上限的波纹实例；主 Shader 与 Qt 预览 Shader 按同一枚举选择线条算法。

**技术栈：** C++、Qt/QML、OpenGL GLSL、现有 CMake/CTest。

## 全局约束

- 默认波纹模式为常驻关闭。
- 默认吸积盘模式为柔化。
- 随黑洞启用仅在黑洞实际渲染进程运行时生效。
- 不修改 CubeMX 或自动生成文件；源码与文档使用 UTF-8。
