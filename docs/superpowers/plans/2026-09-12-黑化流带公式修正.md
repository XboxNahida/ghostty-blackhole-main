# 黑化、流带与全屏公式修正实施计划

> **For agentic workers:** 按节点执行，每个节点完成后运行离屏测试。

**目标：** 修正黑洞移动时黑化错位、单条吸积带脱节，以及公式阶段缺少全屏连续流动的问题。

**架构：** 在现有消费 Shader 中加入当前黑洞中心与移动路径遮罩；桌面、过渡流面、盘面使用三层连续权重；公式作为独立全屏背景层，同时保留中心附近透镜流带。C++ 只增加必要的中心 uniform 上传，不启动实际窗口。

**技术栈：** C++17、OpenGL 3.3、GLSL、现有 GLFW 离屏 GPU 测试。

## 全局约束

- 不启动 `blackhole.exe` 或 Qt UI，不遮挡用户当前画面。
- 保留用户未提交配置改动，不修改其他工作区。
- 所有源码 UTF-8；每个节点更新 `debug_state.md`。
- 只修改与本次视觉问题直接相关的 Shader、主程序 uniform、GPU 测试和中文记录。

### 节点 1：黑化遮罩跟随

- 增加 `uConsumeCenter`，让黑化前沿以当前中心计算，并把原点到当前中心的路径作为软连接区域。
- 测试移动中心时黑化区域随中心移动，已消失区域保持不可恢复。

### 节点 2：流带连续过渡

- 扩大桌面输运层的内外范围，加入宽透明过渡层和渐变边缘。
- 测试输出不再只在一条细带上有桌面贡献，边缘权重连续。

### 节点 3：全屏公式流

- 在 72 秒后生成全屏多尺度公式背景，按连续时间平移并轻微弯曲；中心流带仍可叠加公式。
- 测试公式阶段画面边缘和中心均存在有限公式能量，且时间变化连续。

### 节点 4：集成验证

- 构建 Renderer，运行 CPU/GPU CTest 和既有契约脚本。
- 只生成离屏输出和候选文件，不启动窗口。
