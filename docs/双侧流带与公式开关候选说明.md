# 双侧流带与公式开关候选说明

入口：`build/consumption-options-candidate/appBlakholeUI.exe`。

## 修改

- 小黑洞收薄从仅压缩离盘高度，扩展为同时压缩盘面内的横向跨度。黑洞两侧共用相同的局部收拢规则，随倾角、滚转改变方向；长轴延伸和远处桌面保留。黑洞长大后平滑恢复。
- 高级配置的“吞噬与光影效果”下新增“桌面耗尽后显示公式流带”，默认开启。取消后，桌面耗尽只保留黑洞和独立星空。沿用现有配置保存、启动流程，修改后重新启动效果生效；配置键为 `consumptionFormula`。
- 蓝色/大内径预设的发光衰减改用内径归一化距离，避免绝对距离衰减与入边展开叠加导致额外变暗。色温按等亮度色相比值处理，预设 gain/exposure 仍控制最终亮度，不修改预设数值。

## 验证

- Renderer 构建通过，CTest 3/3；Qt UI 构建通过，已有测试 8/8；兼容、移动及光影检查通过。
- 新增左右截面宽度对称检查，验证左侧也收窄；保留三维倾角、原色融合、耗尽和相位连续回归。
- 公式 GPU 回归验证开关关闭时无公式材质，开启后恢复；UI 属性、配置写入/读取及 Renderer uniform 路径已核对。
- 相同其余参数时，蓝色/暖色盘面亮度比实测约 0.9626。蓝色预设自身较低的 gain/exposure 仍会使其比暖金预设暗，不强行统一所有预设亮度。
- 已查看小黑洞和蓝色盘面的隐藏 GPU 图像。没有交互启动 UI 或全屏 Renderer，未测全屏帧率。
- Renderer 无新增编译警告或错误。UI 构建存在未修改预览代码的 `QImage::mirrored` 弃用警告，以及部署工具缺少可选 DX12 编译器的提示；无编译错误。
